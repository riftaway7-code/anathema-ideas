# intel i219-v ethernet (asus b460 pro wifi board)

from: diamantinoop (discord)

> Add support for intel i219-v for the asus b460 pro wifi board

## notes

wired ethernet is the first network goal (wifi comes later). the intel i219-v is a very common onboard nic, and the hackintosh scene already has open source drivers for it (for example intelmausi), so it is a realistic target.

the board in question (asus b460 pro wifi, intel 10th gen) is a good test target, since it is a common setup. works only after the system boots, so this is blocked on booting.

status: open, high priority for the network stage, blocked on booting
group: wired networking
priority: p2
