# anathema ideas

ideas and addon requests from the anathema discord, one file per idea at `<user>/<idea>.md`.

* **[INDEX.md](INDEX.md)** lists every idea, grouped by area, with duplicates merged and a priority tag (`p1` to `p3`, or `parked`). start there.
* **[writeups/](writeups/)** has longer write-ups of the most-wanted ideas: what would actually have to be built, in what order, and what is still unknown.
* to add an idea, see "adding an idea" at the bottom of the index.
